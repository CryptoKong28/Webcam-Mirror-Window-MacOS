# Mirror Check

A tiny macOS menu bar mirror app.

## Use it

From the project folder, build and open the app:

```sh
./build.sh
open MirrorCheck.app
```

Click the camera/viewfinder icon in the top menu bar to show the mirrored webcam preview.

When the camera is running, click the menu bar icon again to stop the camera.

Right-click the menu bar icon to show the mirror, stop the camera, or quit.

macOS will ask for camera permission the first time the preview opens. If permission is denied, click **Open Camera Privacy Settings** in the popover and enable camera access for Mirror Check.

## Rebuild

```sh
./build.sh
```
